# Lobby Checklist

แอปเช็กลิสต์ตรวจล็อบบี้รายวันในรูปแบบผังมุมบน (top view) ออกแบบให้ใช้บน iPad

- แตะของแต่ละชิ้นบนผัง (โต๊ะ เก้าอี้ ตู้ ตู้เย็น ป้าย ฯลฯ) เพื่อบันทึกสถานะ รายการตรวจ หมายเหตุ และรูปถ่าย
- จุดที่ต้องซ่อมหรือต้องดำเนินการจะแสดงบนผังและในหน้า "งานค้าง" จนกว่าจะกดปิดงาน
- ดูข้อมูลย้อนหลังผ่านปฏิทิน พิมพ์รายงานรายวัน และส่งออก CSV
- แก้ไขผังเองได้ (เพิ่ม ย้าย ปรับขนาด หมุน) และให้ ChatGPT ช่วยจัดผังหรือเขียนรายการตรวจได้ (ใส่ API key ในหน้าตั้งค่า)
- ใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก
- ซิงก์ข้อมูลระหว่าง iPad และคอมพิวเตอร์ผ่าน Firebase (ไม่บังคับ)

## การใช้งาน

เปิดเว็บใน Safari บน iPad แล้วกดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** เพื่อใช้เหมือนแอป

## ข้อมูล

ข้อมูลเก็บในเครื่องที่ใช้งาน (localStorage) จึงใช้งานได้แม้ไม่มีอินเทอร์เน็ต
ถ้าตั้งค่าซิงก์ (ด้านล่าง) ข้อมูลจะถูกส่งขึ้น Firebase และทุกเครื่องที่เข้าสู่ระบบด้วยบัญชีเดียวกันจะเห็นข้อมูลชุดเดียวกันทันที
ควรกด **ตั้งค่า → สำรองข้อมูล (JSON)** เป็นระยะ

## ตั้งค่าซิงก์ iPad กับคอมพิวเตอร์ (Firebase ฟรี)

ทำครั้งเดียว ประมาณ 10 นาที ที่ https://console.firebase.google.com

1. **สร้างโปรเจกต์**: กด *Create a project* ตั้งชื่อ เช่น `lobby-checklist` (ปิด Google Analytics ได้)
2. **เปิดการเข้าสู่ระบบด้วยอีเมล**: เมนู *Build → Authentication → Get started → Sign-in method → Email/Password* → เปิด *Enable* → *Save*
3. **สร้างบัญชีสำหรับทีม**: *Authentication → Users → Add user* ใส่อีเมลและรหัสผ่าน (ทุกเครื่องจะใช้บัญชีนี้)
4. **สร้างฐานข้อมูล**: *Build → Firestore Database → Create database* → เลือก location `asia-southeast1 (Singapore)` → *Start in production mode*
5. **ตั้งสิทธิ์การเข้าถึง**: ในหน้า Firestore แท็บ *Rules* วางข้อความจากไฟล์ [`firestore.rules`](firestore.rules)
   แล้วแก้ `lobby@example.com` เป็นอีเมลจากข้อ 3 (ใส่ได้หลายอีเมล คั่นด้วยจุลภาค) → *Publish*
6. **เอา config**: ⚙️ *Project settings → General → Your apps* → กดไอคอน `</>` (Web) → ตั้งชื่อ → *Register app*
   แล้วคัดลอกส่วน `const firebaseConfig = { ... }`
7. **ใส่ในแอป**: กดปุ่ม ☁ มุมขวาบน → วาง config → *บันทึก config* → เข้าสู่ระบบด้วยอีเมลจากข้อ 3
   ทำแบบเดียวกันในทุกเครื่อง (หรือใส่ config ไว้ในตัวแปร `FIREBASE_CONFIG` ใน `index.html` ครั้งเดียว แล้วทุกเครื่องแค่เข้าสู่ระบบ)

ค่า `firebaseConfig` ไม่ใช่ความลับ เปิดเผยได้ ความปลอดภัยของข้อมูลอยู่ที่ Rules ในข้อ 5 ซึ่งอนุญาตเฉพาะอีเมลที่ระบุ

เมื่อเข้าสู่ระบบครั้งแรกในเครื่องที่มีข้อมูลอยู่แล้ว แอปจะถามว่าจะ *ใช้ข้อมูลออนไลน์* (แทนที่ข้อมูลในเครื่อง) หรือ *รวมข้อมูล*
ถ้าไม่มีอินเทอร์เน็ตก็ใช้งานได้ตามปกติ ข้อมูลจะถูกส่งขึ้นเมื่อกลับมาออนไลน์ ถ้าสองเครื่องแก้จุดเดียวกัน ข้อมูลที่บันทึกทีหลังจะถูกใช้

API key ของ OpenAI ถูกเก็บไว้ในเครื่องเท่านั้น และไม่รวมอยู่ในไฟล์สำรองข้อมูล

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | ตัวแอปทั้งหมด (HTML/CSS/JS ไฟล์เดียว) |
| `manifest.webmanifest`, `icons/` | ไอคอนและการติดตั้งเป็นแอปบนหน้าจอโฮม |
| `sw.js` | ให้แอปเปิดได้ตอนไม่มีอินเทอร์เน็ต |
| `firestore.rules` | สิทธิ์การเข้าถึงฐานข้อมูล Firebase (ใช้ในขั้นตอนตั้งค่าซิงก์) |
